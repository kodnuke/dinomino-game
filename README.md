## Features

- Hatch eggs in incubation nests
- Merge two dinosaurs in the Love Cloud to discover new species
- Run shops and earn coins to grow your park
- Big, kid-friendly joystick controls
- Automatic save and load

## How it was built

Dinomino started as a gift for my little cousin, who loves dinosaurs. I am not a game developer, so I built it over a few weekends by directing AI ("vibe coding"):

1. Describe the feature in plain language
2. Playtest on a real phone
3. Screenshot what looks wrong and send it back with one sentence
4. Repeat

The AI handled 3D scenes, game logic and UI. The hard parts were keeping save/load compatible as features grew, mobile performance, and store submission.

## Tech

- [Three.js](https://threejs.org) for 3D rendering
- Wrapped as a native app for iOS, iPadOS and Android
